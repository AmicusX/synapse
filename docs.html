Служебные файлы приложения

Это не инструкции, а части самого Синапса. Они должны лежать в той же папке, что и index.html, иначе приложение не установится на домашний экран и не будет работать офлайн.

Как всё выложить и открывать

  1. Соберите все файлы в одну папку на компьютере: инструкции .html плюс четыре служебных файла.
  2. Откройте свой репозиторий на GitHub → Add file → Upload files → перетащите все файлы сразу → Commit changes.
  3. Файлы должны лежать в корне репозитория, рядом друг с другом — не внутри вложенной папки.
  4. Подождите 1–2 минуты, пока GitHub Pages обновится.
  5. Откройте эту страницу по адресу сайта: …/docs.html
  6. Нажмите «Проверить файлы» — увидите, какие инструкции загружены, а какие ещё нет.
  7. Добавьте страницу на домашний экран айфона: Safari → Поделиться → «На экран Домой». Получится «пульт» со всеми инструкциями.
Все ссылки внутри этой страницы относительные: страница сама подхватывает адрес, по которому открыта. Работает и на GitHub Pages, и на вашем домене после переезда на VPS — ничего переписывать не нужно.
Переезд на Beget VPS: скопируйте все эти файлы в /var/www/synapse — центр инструкций станет доступен по адресу https://вашдомен/docs.html.

Публичный репозиторий означает, что любой может открыть исходники. Но настройки приложения в исходниках не хранятся: ключ, модель и чаты лежат в localStorage конкретного браузера. Другой человек, открывший ваш сайт, увидит пустое приложение со своими настройками. Опасность в другом — в файлы попали ваши личные адреса как примеры.

Видно всем
  • Весь код всех HTML-файлов, включая инструкции
  • Домен mnetaknado.ru — вписан в примеры
  • Адрес воркера synapse-relay.amicus0206.workers.dev
  • Адрес провайдера ai.starimg.ru — значение по умолчанию
  • История коммитов: удалённое позже остаётся в истории
Видно только вам
  • API-ключ — localStorage вашего браузера
  • Все чаты и история переписки
  • Выбранная модель и настройки поиска
  • Отметки прогресса в инструкциях
  • Другой посетитель получает своё пустое хранилище
Важное исключение: файл экспорта JSON, который вы скачиваете кнопкой «Экспорт», содержит ключ открытым текстом. Если такой файл попадёт в репозиторий или в переписку — ключ утечёт. Никогда не коммитьте бэкапы.
Приватный репозиторий не прячет сайт. GitHub Pages отдаёт страницы публично даже из приватного репозитория, а исходники читаются через «просмотр кода страницы». Секрет в клиентском файле не бывает секретом. Плюс на бесплатном тарифе GitHub Pages работает только из публичного репозитория.

Сканирование ваших файлов

Страница скачает файлы с того же адреса, где она открыта, и поищет в них ключи, домены, адреса воркеров, IP и почты. Ничего никуда не отправляется — всё считается в вашем браузере.

Как убрать личное из файлов

  1. Запустите сканирование выше. Для каждого файла с находками появится кнопка «Скачать очищенную копию».
  2. В очищенной копии ваш домен заменён на вашдомен.ru, адрес воркера — на ваш-воркер.workers.dev, найденные ключи вырезаны.
  3. Загрузите очищенные файлы в репозиторий поверх старых: Add file → Upload files → Commit changes.
  4. Если ключ всё-таки нашёлся в файле — сразу перевыпустите его у продавца. Удаление из файла не помогает: ключ уже мог быть скопирован, и он остаётся в истории коммитов.
  5. Воркер больше не нужен для работы приложения. Либо удалите его в Cloudflare, либо задайте переменную RELAY_SECRET, чтобы им не пользовались посторонние.
После замены файлов запустите сканирование ещё раз — счётчик личных данных должен обнулиться.

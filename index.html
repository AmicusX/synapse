Провайдер ИИ

Например https://ai.starimg.ru/v1 или https://api.openai.com/v1
Нужно для ai.starimg.ru: сервер не отдаёт CORS-заголовки, браузер блокирует запросы. Разверните relay/worker.js на Cloudflare Workers (бесплатно) и вставьте адрес. Ключ передаётся только через ваше реле.

Поиск в интернете

«Контекст» работает даже с прокси, которые не поддерживают tools.
Авто-режим ходит через публичные CORS-прокси (allorigins и др.) — учитывайте это для приватных запросов.
Инстанс должен разрешать CORS и format=json.

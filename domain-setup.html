Домен остаётся у вашего регистратора, продлевать там же. Мы направляем его на Cloudflare через NS-серверы, а затем вешаем на воркер адрес вида relay.вашдомен.ru. Ниже — четыре этапа с картинками нужных экранов и живыми проверками.

Сначала прочитайте: для Синапса это уже не обязательно

С тех пор, как писалась эта инструкция, изменились две вещи.

  1. Продавец включил CORS на ai.starimg.ru — приложение подключается напрямую, без реле и без VPN. Поле «CORS-реле» в настройках можно оставить пустым.
  2. Cloudflare блокируется российскими операторами. Свой домен поверх Cloudflare это не лечит: имя другое, а IP-адреса те же. Поэтому путь «домен + Cloudflare» не даёт выигрыша.
Куда деть домен с пользой: направить его на российский VPS и разместить там сайт и реле (этап 5 ниже), либо использовать для вашего проекта обучения вокалу. Домен — актив, он не пропадёт.

01Добавьте домен в Cloudflare

  1. Откройте dash.cloudflare.com и войдите.
  2. На главной странице аккаунта нажмите Add a site (или «+ Add» → «Domain»). Не видно кнопки — используйте ссылку ниже.
  3. В поле Enter your domain впишите вашдомен.ru → Continue.
  4. Выберите план Free — $0 (внизу списка) → Continue.
  5. На экране «Review DNS records» ничего не меняйте → Continue. DNSSEC и «Quick scan» не включайте.
  6. Появится экран Change your nameservers с двумя NS. Скопируйте оба в поля вверху страницы.

02Замените NS у регистратора

Здесь вы говорите регистратору: «DNS этого домена обслуживает Cloudflare». Выберите своего регистратора.

  1. Войдите на reg.ru → раздел Домены.
  2. Нажмите на домен вашдомен.ru.
  3. Блок DNS-серверы (или «NS-серверы») → Изменить.
  4. Выберите Свои DNS-серверы / снимите галочку «серверы регистратора».
  5. NS1 = lara.ns.cloudflare.com, NS2 = ned.ns.cloudflare.com. NS3/NS4 пустые.
  6. Сохранить → подтвердите по SMS или письму, если попросят.

Кабинет NIC.RU
  1. Войдите в кабинет регистратора, где куплен домен.
  2. Найдите раздел DNS-серверы / Nameservers / Делегирование.
  3. Переключите на «свои / custom nameservers», впишите оба NS из Cloudflare, сохраните.
Не путайте NS-серверы домена (делегирование — то, что нужно) с NS-записями внутри DNS-зоны. Редактировать нужно делегирование у регистратора.
DNSSEC: если он включён у регистратора — сначала выключите и подождите пару часов, иначе после смены NS домен может перестать открываться. У свежекупленных .ru обычно выключен.
Сколько ждать: для .ru обычно 15–60 минут, по правилам до 24 часов. Ускорить нельзя — изменения расходятся по DNS постепенно.

04Привяжите поддомен к воркеру

Домен Active? Вешаем на воркер адрес relay.вашдомен.ru. Делается со стороны воркера — Cloudflare сам создаст DNS-запись и выпустит сертификат.

  1. Cloudflare → Workers & Pages → откройте воркер synapse-relay.
  2. Вкладка Settings → раздел Domains & Routes.
  3. Add → тип Custom Domain (не Route!).
  4. Впишите relay.вашдомен.ru → Add Custom Domain.
  5. Подождите 2–10 минут: выпускается SSL-сертификат. Запись в DNS появится сама, с оранжевым облаком.

Custom Domain, а не Route. Route требует уже существующую запись и работает иначе. Custom Domain сам создаёт запись и сертификат — это наш путь.

05Рабочая альтернатива: домен на российский сервер

Этот вариант решает проблему блокировки по-настоящему: домен указывает напрямую на IP российского VPS, минуя Cloudflare. Сайт и реле живут на одном адресе, поэтому CORS не мешает вовсе.

Через Cloudflare

Proxied

relay → IP Cloudflare → блокировка оператором

Напрямую на VPS

DNS only

@ → IP вашего сервера → работает без VPN

  1. Арендуйте VPS у российского провайдера (Beget, Timeweb, RuVDS) с Ubuntu 24.04.
  2. Cloudflare → домен → DNS → удалите запись relay и все записи, указывающие на Cloudflare.
  3. Создайте запись: тип A, имя @, значение — IP вашего VPS, облако серое (DNS only).
  4. Разверните сайт и реле на сервере — подробная инструкция с готовым скриптом в разделе Beget VPS.
  5. Адрес реле станет https://вашдомен.ru/relay — проверьте его кнопкой ниже.

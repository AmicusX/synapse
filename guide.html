Соберите файлы в одну папку 3 мин

Нужно 5 файлов. Четыре маленьких можно скачать кнопками ниже, главный — скопировать из ответа с кодом.
  1. Создайте на компьютере папку, например synapse.
  2. Скачайте 4 файла кнопками ниже — они попадут в «Загрузки», перенесите их в папку.
  3. Главный файл index.html — это первый большой блок кода из ответа, где вам дали сайт. Скопируйте его целиком в текстовый редактор (Блокнот / TextEdit) и сохраните в папку под именем index.html.

07

Сделайте личное реле на Cloudflare 5 мин

Реле — ваш личный посредник: браузер → ваше реле → ai.starimg.ru. Бесплатно, карта не нужна.
  1. Откройте dash.cloudflare.com → зарегистрируйтесь (почта + пароль) и подтвердите почту.
  2. В меню слева нажмите Workers & Pages → кнопку Create → вкладку Workers → Create Worker.
  3. Имя: synapse-relay → нажмите Deploy.
  4. Нажмите Edit code. Откроется редактор. Удалите весь код слева (Ctrl+A → Delete) и вставьте код ниже.
  5. Нажмите Deploy ещё раз (справа вверху).
  6. Скопируйте адрес воркера — он показан сверху, вида https://synapse-relay.имя.workers.dev — и вставьте в поле ниже.

worker.js — вставить целиком
const DEFAULT_ALLOWED = ["ai.starimg.ru"];
const CORS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
  "Access-Control-Allow-Headers": "authorization, content-type, x-target-url, x-relay-key",
  "Access-Control-Max-Age": "86400",
};
export default {
  async fetch(req, env) {
    if (req.method === "OPTIONS") return new Response(null, { status: 204, headers: CORS });
    const url = new URL(req.url);
    const target = req.headers.get("x-target-url") || url.searchParams.get("target");
    const json = (obj, status) => new Response(JSON.stringify(obj), { status, headers: { ...CORS, "Content-Type": "application/json" } });
    if (!target) return json({ error: "Передайте целевой URL в заголовке x-target-url или ?target=" }, 400);
    let t;
    try { t = new URL(target); } catch { return json({ error: "Некорректный целевой URL" }, 400); }
    if (t.protocol !== "https:") return json({ error: "Разрешён только https" }, 403);
    const allowed = (env.ALLOWED_TARGETS || DEFAULT_ALLOWED.join(",")).split(",").map(s => s.trim()).filter(Boolean);
    if (allowed.length && !allowed.includes(t.hostname)) return json({ error: "Хост не в списке разрешённых: " + t.hostname }, 403);
    if (env.RELAY_SECRET && req.headers.get("x-relay-key") !== env.RELAY_SECRET) return json({ error: "Неверный секрет реле" }, 401);
    const headers = new Headers(req.headers);
    ["x-target-url", "x-relay-key", "host", "origin", "referer", "cf-connecting-ip", "cf-ray", "cf-visitor", "x-forwarded-for", "x-real-ip"].forEach(h => headers.delete(h));
    const resp = await fetch(t.toString(), {
      method: req.method,
      headers,
      body: ["GET", "HEAD"].includes(req.method) ? undefined : req.body,
      redirect: "follow",
    });
    const out = new Headers(resp.headers);
    Object.entries(CORS).forEach(([k, v]) => out.set(k, v));
    return new Response(resp.body, { status: resp.status, headers: out });
  },
};
Теперь в Синапсе: Настройки → поле CORS-реле → вставьте этот адрес. Ключ проходит только через ваше реле — чужие посредники не используйте.
Адрес workers.dev не открывается в России — что делать
У части операторов РФ домены workers.dev заблокированы. Решение: в воркере откройте Settings → Domains & Routes → Add → Custom Domain и привяжите свой домен (например relay.вашдомен.ru, домен должен быть добавлен в Cloudflare). Тогда в настройках Синапса указывайте этот домен вместо workers.dev. Проверить доступность можно, просто открыв адрес реле в Safari — должен появиться текст про x-target-url.
Хочу защитить реле паролем (необязательно)
В воркере: Settings → Variables → Add → имя RELAY_SECRET, значение — любой ваш пароль → Deploy. В Синапсе в поле «Секрет реле» впишите тот же пароль. Без этого шага реле тоже работает.

Частые вопросы и проблемы

Chatbox на iOS отправляет запросы через встроенный браузер, который требует от сервера «разрешение» (CORS-заголовки). Сервер ai.starimg.ru его не даёт — запрос блокируется. На компьютере Chatbox это правило игнорирует, поэтому там работало. Наш сайт ходит через ваше личное реле, которое добавляет разрешение — и всё работает.
Да. GitHub Pages бесплатен для публичных репозиториев. Cloudflare Workers бесплатен до 100 000 запросов в день — для личного чата это годы. Платите вы только продавцу ключа за токены модели, как и раньше.
Три причины по частоте: 1) прошло меньше 2–3 минут — подождите и обновите; 2) файл называется не index.html (например Index.html или index.html.txt) — переименуйте; 3) файлы лежат внутри папки, а не в корне репозитория — переместите. Кнопка «Проверить, что сайт ожил» в шаге 4 подскажет точнее.
Значит, запрос идёт напрямую к ai.starimg.ru без реле. Сделайте шаг 7 и вставьте адрес воркера в поле «Реле». Если реле уже указано, но ошибка осталась — откройте адрес реле в Safari: должен появиться текст про x-target-url. Если не открывается — ваш оператор блокирует workers.dev, привяжите свой домен (раскрывашка в шаге 7).
Ключ отклонён. Скопируйте его заново из личного кабинета продавца целиком, без пробелов в начале и конце. Проверьте, что тот же ключ работает в Chatbox на компьютере. Если задавали RELAY_SECRET — он должен совпадать в воркере и в поле «Секрет реле».
Проверьте API Host: для ai.starimg.ru правильно https://ai.starimg.ru/v1 (с /v1 на конце). Если вписали имя модели вручную — оно должно точно совпадать с тем, что отдаёт кнопка «Проверить и получить модели» в шаге 8.
В Синапсе: Настройки → Поиск → режим «Контекст: искать до ответа» — он работает даже если провайдер не поддерживает инструменты. Движок «Авто» не требует ключей, но ходит через публичные прокси и иногда недоступен — тогда вставьте бесплатный ключ Tavily (tavily.com) или выберите другой движок.
